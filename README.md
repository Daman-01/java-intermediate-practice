# Java Intermediate Practice

A collection of intermediate Java practice programs created while improving problem-solving skills and learning important Java concepts.

## Topics Covered

- Arrays
- One-dimensional arrays
- Two-dimensional arrays
- Array input and output
- String arrays
- Conditional statements
- Factorial
- Temperature conversion
- Menu-driven calculator
- User input using `Scanner`
- Basic problem-solving

## Project Structure

### Advance Calculator

Contains a menu-driven calculator program that performs:

- Addition
- Subtraction
- Division
- Multiplication

### Array Programs

Contains programs related to:

- Creating and printing arrays
- Taking array input from the user
- Working with string arrays
- Two-dimensional arrays

### Java Concept Programs

Contains:

- Factorial program
- Conditional statement program
- Temperature converter

## Technologies Used

- Java
- IntelliJ IDEA

This repository documents my Java learning progress and contains practice programs created while developing programming logic and problem-solving skills.
